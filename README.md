# Виджет банковских операций

### В этом проекте происходит разработка виджета, который показывает несколько последних успешных банковских операций клиента.

## Установка проекта :
1) Клонируйте репозиторий к себе на компьютер с помощью команды `git clone`
2) Проект использует poetry, поэтому для использования проекта установите его. И установите зависимости с помощью `poetry install`
3) Проект на данный момент на стадии разработки. В будущем будет добавлена точка входа в модуле `main.py`

## Описание функционала:
На данный момент в проекте есть 3 модуля:
1) masks:
- Функция get_mask_card_number для максировки номера карты
```python
get_mask_card_number(7000792289606361)
>>> '7000 79** **** 6361'
```
- Функция get_mask_account для маскировки номера счета
```python
get_mask_account(73654108430135874305 )
>>> **4305
```

2) processing
- Функция filter_by_state возвращает на выбор все отмененные или выполненные операци

- Функция sort_by_date сортирует операции по дате

3) widget
- Функция mask_account_card для определения и максировки номера карты или счета
```python
mask_account_card(Visa Platinum 7000792289606361)
>>> Visa Platinum 7000 79** **** 6361
```
- Функция get_date для форматирования даты из полного формата в формат "ДД.ММ.ГГГГ"
```python

```

4) generators 
- Функция filter_by_currency для отбора транзакций по заданной валюте.  
На вход передается список словарей и нужная валюта. Функция генерирует итератор, который поочередно вернет транзакции
с нужной валютой. Если список на входе пустой или нет нужной валюты - ничего не вернет, ошибки не будет.
```python
filter_by_currency(transactions_for_test, 'USD')
>>> {
            "id": 939719570,
            "state": "EXECUTED",
            "date": "2018-06-30T02:08:58.425572",
            "operationAmount": {
                "amount": "9824.07",
                "currency": {
                    "name": "USD",
                    "code": "USD"
                }
            },
            "description": "Перевод организации",
            "from": "Счет 75106830613657916952",
            "to": "Счет 11776614605963066702"
        }
```
- card_number_generator  
Генерирует номер карты в заданном в диапазоне. Генерация начинается с 20 нулей и каждый раз
прибавляется единица из заданного в параметрах промежутка. Генерация может происходить, условно, бесконечно.
```python
test_card = card_number_generator(3, 7)
>>> "0000 0000 0000 0000 0003",
    "0000 0000 0000 0000 0004",
    "0000 0000 0000 0000 0005",
    "0000 0000 0000 0000 0006",
    "0000 0000 0000 0000 0007"
```
- transaction_descriptions  
Функция принимает список словарей из транзакций, формирует итератор из описаний
и возвращает описание этой транзакции по одной при обращении к итератору.
```python

        {
            "id": 939719570,
            "state": "EXECUTED",

            "operationAmount": {
                "amount": "9824.07",
                "currency": {
                    "name": "USD",
                    "code": "USD"
                }
            },
            "description": "Перевод организации",
            "from": "Счет 75106830613657916952",
            "to": "Счет 11776614605963066702"
        },
        {
            "id": 142264268,
            "state": "EXECUTED",
            "date": "2019-04-04T23:20:05.206878",
            "operationAmount": {
                "amount": "79114.93",
                "currency": {
                    "name": "USD",
                    "code": "USD"
                }
            },
            "description": "Перевод со счета на счет",
            "from": "Счет 19708645243227258542",
            "to": "Счет 75651667383060284188"
        }]

descs = transaction_descriptions(transactions)
next(descs) >>> "Перевод организации"

```
