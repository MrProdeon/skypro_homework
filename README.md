# Виджет банковских операций

### Проект направлен на разработку виджета, который показывает несколько последних успешных банковских операций клиента.
### Учитывается банковская информационная безопасность, ввиде максировки реквизитов.
### Виджет поддерживает фильтрацию операций по статусу, валюте, возрастанию, дате, слову в описании.

## Установка проекта :
1) Клонируйте репозиторий к себе на компьютер с помощью команды `git clone`
2) Проект использует poetry, поэтому для использования проекта установите его. И установите зависимости с помощью `poetry install`
3) Точка входа - `main.py`

5) decorators
- Декоратор log.  
Декоратор, который логирует информацию о выполнении функции.  
Если функция выполнена успешно - отдаст сообщение об успехе с именем функции и результатом.  
В случае исключения - отдаст имя функции, ошибку и входные параметры.  
По умолчанию отдает в консоль, но можно необязательным параметром в декоратор передать имя файла, в который
будут записаны финальные данные.
```python
@log()
def get_dif(a, b):
    return a / b

get_dif(1, 2)
>>> "Успех! Имя функции : get_dif\nРезультат : 0.5\n"

get_dif(1, 0)
>>> "Исключение!\nИмя функции : get_dif\nОшибка : division by zero\nВходные параметры : ((1, 0), {})\n"

@log(file)
    def get_dif(a, b):
        return a / b
get_dif(1, 2)
>>> Запись в файл "Успех! Имя функции : get_dif\nРезультат : 0.5\n"

get_dif(1, 0)
>>> Запись в файл "Исключение!\nИмя функции : get_dif\nОшибка : division by zero\nВходные параметры : ((1, 0), {})\n"

```
6) utils
- Функция get_info_about_operation  
Принимает путь до JSON-файл с операциями и возвращает Python-объект из него
    Возвращает пустой список если :
    1) Файл пустой
    2) Вернулся объект, который не является списком
    3) Файл не найден  
  4) 
logger.info() — используется для информирования о ходе выполнения (начало работы, успешная загрузка и т.д.).  
logger.exception() — фиксирует ошибку, если файл не найден.
Пример использования :
```python
operations = get_info_about_operation("operations.json")

if operations:
    print(f"Загружено операций: {len(operations)}")
else:
    print("Файл не найден или пуст.")

```

- Функция get_amount_of_transaction  
Функция возвращает сумму транзакции в рублях.
Если транзакция в долларах (USD) или евро (EUR) - автоматически конвертирует в рубли через API.

```python
transaction_usd = {
    "operationAmount": {
        "amount": "100",
        "currency": {"code": "USD"}
    }
}

transaction_rub = {
    "operationAmount": {
        "amount": "5000",
        "currency": {"code": "RUB"}
    }
}

amount_in_rub_usd = get_amount_of_transaction(transaction_usd)
amount_in_rub_rub = get_amount_of_transaction(transaction_rub)

print(f"Сумма в рублях (USD): {amount_in_rub_usd}")
print(f"Сумма в рублях (RUB): {amount_in_rub_rub}")
>>>
Сумма в рублях (USD): 10250.0
Сумма в рублях (RUB): 5000.0

```

9) main.py  
Функция для сборки всего функционала в единое целое. Предоставляет пользовательский интерфейс в консоли
для взаимодействия.
Пользователь выбирает какой файл с операциями он хочет обработать. Исходя из его выбора, функция корректно
обрабатывает именно то, что необходимо.
Далее пользователь указывает, каким именно способом отфильтровать выбранный им файл, так же с помощью условных
операторов функция делает только то, что от неё просят.
После всех проверок и сортировок выводит в консоль результат.
Пример использования :
```python
if __name__ == "__main__":
    main()

```
